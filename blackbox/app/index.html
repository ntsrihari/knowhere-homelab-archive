LIVE LOCATION INGEST

Connect GPSLogger to Knowhere

Per vehicle

Select a vehicle, copy its private URL into GPSLogger → Settings → Log to custom URL. Turn that option on. Every new location fix is sent directly to Knowhere; GPX export becomes optional for ongoing tracking.

Requires Tailscale connected on the phone.

Automatic vehicle selection

Use each car's distinct Bluetooth head-unit name as the trigger. In GPSLogger, create one profile per vehicle and paste that vehicle's unique URL into that profile. In the free Automate app, make one flow per head unit: when it connects, broadcast a switch to the matching GPSLogger profile and start logging; when it disconnects, stop logging. Distinct profiles send points with distinct vehicle keys, so the server assigns their costs to the right car. This is a Bluetooth proxy for Android Auto, not a trustworthy signal from Android Auto itself. If both cars share a Bluetooth name or wired connection does not expose a distinct connection, this method cannot auto-differentiate them.

Exact GPSLogger broadcast for Automate

On Bluetooth connected: add an Automate “Broadcast send” block:

Package
com.mendhak.gpslogger
Receiver class
com.mendhak.gpslogger.TaskerReceiver
Action
com.mendhak.gpslogger.TASKER_COMMAND
Extras
switchprofile = the exact GPSLogger profile name; immediatestart = Boolean true

On Bluetooth disconnected: send the same package/class/action with immediatestop = Boolean true.

Test each car while parked. Give each head unit a distinct connection name in Vehicle settings. If the Android Auto session doesn't cause a distinct Bluetooth connection, profile switching will need another trigger or manual selection.

This is a Bluetooth-based proxy for Android Auto, not direct proof that projection is active. It works when each head unit exposes a distinct connected Bluetooth device. Bluetooth connection names and connection permissions vary by phone/Android version. Keep the manual vehicle selector as fallback.
